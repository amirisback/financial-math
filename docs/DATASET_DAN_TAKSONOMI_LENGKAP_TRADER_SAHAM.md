### 4.2 Simulasi Perhitungan Position Sizing 1% Riil (BEI)
- **Total Modal Portofolio:** Rp 100.000.000
- **Batas Risiko 1%:** $\text{Risk}_{\text{IDR}} = \text{Rp } 1.000.000$
- **Saham Target:** PTBA
- **Harga Beli (Entry):** Rp 2.600
- **Stop Loss Teknikal:** Rp 2.470 (Support terdekat)
- **Jarak Risiko ($\Delta_{\text{Risk}}$):** $\text{Rp } 2.600 - \text{Rp } 2.470 = \text{Rp } 130 \text{ per lembar (5.0\%)}$
- **Alokasi Lot Maksimal:**
  $$\text{Maks Lembar} = \frac{\text{Rp } 1.000.000}{\text{Rp } 130} = 7.692 \text{ lembar}$$
  $$\text{Maks Lot} = \left\lfloor \frac{7.692}{100} \right\rfloor = \mathbf{76 \text{ Lot}}$$
- **Nilai Transaksi:** $76 \text{ Lot} \times 100 \times \text{Rp } 2.600 = \text{Rp } 19.760.000$ (19.76% dari total modal portofolio).
- **Hasil Proteksi:** Jika PTBA anjlok dan menyentuh Stop Loss di Rp 2.470, kerugian moneter riil portofolio tepat **Rp 988.000 (< 1% modal)**.

### 4.3 Pembedahan Matematis Keruntuhan RRR Scalper di BEI
- **Komisi Transaksi BEI:** Fee beli 0.15%, Fee jual 0.25% + PPh 0.1% = Round-trip $\approx 0.40\%$.
- Misalkan Scalper bermain di saham fraksi Rp 500 (1 tick = Rp 2 atau 0.40%):
  - Target Take Profit: 2 tick = $+0.80\%$
  - Target Stop Loss: 1 tick = $-0.40\%$
  - Target RRR Teoritis: $2 : 1$
- **Kenyataan Net Riil Pasca Fee:**
  - Net Profit = $+0.80\% - 0.40\% = \mathbf{+0.40\%}$
  - Net Loss = $-0.40\% - 0.40\% = \mathbf{-0.80\%}$
  - **Efektif RRR Berbalik 180 Derajat:** Menjadi **$1 : 2$ (Inverted RRR)**!
  - Break-Even Win Rate ($WR_{\text{BE}}$) yang dibutuhkan:
    $$WR_{\text{BE}} = \frac{\text{Loss}}{\text{Gain} + \text{Loss}} = \frac{0.80\%}{0.40\% + 0.80\%} = \mathbf{66.7\%}$$
  - Kesimpulan: Jika Win Rate Scalper di BEI berada di angka 60%, akun tersebut dipastikan **bangkrut secara matematis (*sure mathematical ruin*)** karena terkuras oleh friksi komisi bursa.

## 5. DOKUMEN SISTEM: THE IHSG HYBRID EDGE PLAYBOOK

Bagi pengelolaan portofolio *Wise Stock Robot*, seluruh data di atas dirangkum menjadi satu protokol 5 langkah:
1. **Rezim Makro Sektor:** Identifikasi sektor unggulan via *Darmawan Business Cycle Clock*.
2. **Kualitas Fundamental:** Filter emiten dengan EPS Growth > 15-25% atau NCAV Undervalued via *Adrian Equity Research*.
3. **Konfirmasi Aliran Dana:** Validasi tidak adanya distribusi oleh broker institusi (Top Broker Net Accumulation) via *Clarissa Bandarmologi*.
4. **Presisi Setup Grafik:** Eksekusi saat konfirmasi pola VCP, Wyckoff Spring, atau S/R Flip via *Arya Chartist*.
5. **Kunci Risiko 1%:** Hitung lot menggunakan formula *Bramantyo Position Sizing* dan pasang *Auto-Order Stop Loss (GTC)*.
